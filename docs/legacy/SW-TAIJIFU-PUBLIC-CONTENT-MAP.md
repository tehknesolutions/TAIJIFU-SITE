## Current official boundary

The current interactive site already has official bodies for Manifesto, Fundamentos, TAI, JI, FU, Método, Graduação, Influências and História in `apps/interactive-web/src/content/official-page-content.ts`.

Those bodies remain authoritative. SW-TAIJIFU material does not replace, downgrade or silently merge into them.

The semantic renderer publishes official content only when the route/locale is release-ready; otherwise it exposes an explicit pending state rather than inventing copy.

## Promotion record

No family in this map is promoted by this document.

A promotion requires the source path/revision, target route, conflict review, accepted material, deliberate exclusions and resulting authority state to be recorded.

## Product rule

The objective is to make public pages substantive by recovering compatible source material, not to fill empty UI. If a legacy source cannot be validated against current authority, it remains provenance-only.
