## Reconciliation rule

Each recovered item must be classified before promotion:

- CANON
- OFFICIAL_PRODUCT
- SOURCE
- EVIDENCE
- LEGACY
- EXPERIMENTAL
- UNRESOLVED

A historical assistant recommendation is evidence of a proposal, not proof that the proposal became an official decision. A user decision is authoritative for project direction but still must be represented in the appropriate domain (Canon, product, governance, legacy, etc.).
