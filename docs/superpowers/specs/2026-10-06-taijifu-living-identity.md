# TAIJIFU Living Identity — Arcane-Inspired Design Direction

Status: DESIGN DIRECTION / PROPOSAL
Date: 2026-10-06
Repository authority: TAIJIFU-SITE

## Intent

Evolve the official TAIJIFU visual identity using the systemic discipline demonstrated by TKN ARCANE without copying TKN ARCANE's identity, canonical glyphs, geometry, or runtime.

TAIJIFU remains TAIJIFU. ARCANE is a reference for how a visual language can encode semantics, intensity, geometry, material, motion, and provenance.

## Core identity grammar

TAI — ESSÊNCIA — "O que deve permanecer?"
JI — ADAPTAÇÃO — "O que precisa mudar?"
FU — MANIFESTAÇÃO — "Que forma deve existir agora?"

The visual system itself must obey this grammar:

- TAI defines identity invariants.
- JI defines permitted dimensions of adaptation.
- FU is the concrete manifestation produced for a context.

## Canon → Identity → Manifestation

### Canon
Defines meaning, provenance, canonical topology, doctrine, names, and protected relationships.

### Identity
Defines the reusable TAIJIFU visual grammar: TAI/JI/FU roles, color semantics, typography, materials, geometry, spatial hierarchy, motion, mark behavior, and accessibility.

### Manifestation
Applies the identity to a concrete context without altering Canon.

## Visual semantics

### TAI
Role: permanence, axis, essence, invariant.
Visual behavior: stable geometry, structural mass, deliberate movement.
Identity: red.

### JI
Role: adaptation, transition, relation, response.
Visual behavior: orbital/relational movement, transition, responsive geometry.
Identity: blue.

### FU
Role: manifestation, emergence, result, presence.
Visual behavior: emission, illumination, resolution, materialization.
Identity: gold.

### Integration
Role: synthesis of TAI/JI/FU.
Visual behavior: precision, clarity, connective light/material.
Identity: calibrated neutral/metal/light, not a replacement for the triad.

### HNK
Role: genealogy/provenance.
HNK must not become the primary visual identity of TAIJIFU.

## Manifestation intensity

Inspired by ARCANE's separation of signal/artifact/ritual, TAIJIFU adopts the principle of semantic intensity. Names remain provisional until implementation canonization.

### Signal
Routine interface communication: navigation, labels, state indicators, fine lines, controls.
Low visual energy. No spectacle.

### Artifact
Knowledge made spatial/material: Núcleo, Caminho, Faixa, principle, technique, map object.
Moderate depth and energy. The object should feel meaningful but usable.

### Ritual
Reserved for threshold experiences: official Home hero, entering the Dojo, major Path transitions, selected canonical moments.
Highest depth and energy.
Ritual must remain rare; if everything is ritual, nothing is ritual.

## No Topology Drift

A TAIJIFU manifestation may adapt:
- scale;
- material;
- depth;
- illumination;
- motion;
- spatial context;
- responsive composition.

It must not silently alter:
- canonical meaning;
- protected mark topology;
- TAI/JI/FU semantic roles;
- canonical hierarchy;
- provenance;
- official terminology.

A render is not authorized to invent a replacement symbol merely because it is aesthetically compatible.

## Official Home direction

The supplied official cinematic dojo reference remains the visual target for hierarchy and atmosphere.

The first viewport should read as a RITUAL manifestation:
- cinematic dojo environment;
- official TAIJIFU identity in the header;
- dominant canonical TAIJIFU mark/manifestation;
- TAIJIFU title;
- "ARTE MARCIAL DE SE ADAPTAR";
- the two doctrine banners in their official lateral roles;
- centered TAI/JI/FU triad;
- primary ENTRAR NO DOJO action;
- provenance/authorship and HNK as secondary information.

TAI/JI/FU remain together in the central doctrine system. They do not replace the two lateral doctrine banners.

Existing editorial material may continue below the fold or move to its appropriate canonical route, but must not displace the official hero hierarchy.

## Dojo direction

The Dojo should use spatial knowledge rather than flattening the canon into a dashboard/card grid.

Canonical structure remains:
10 Faixas → 32 Caminhos → 128 Núcleos.

Potential visual mapping:
- Faixa: large-scale region/level;
- Caminho: trajectory/relationship;
- Núcleo: spatial Artifact;
- transitions: meaningful movement between canonical relationships;
- Practice Mode: focused manifestation of the current instructional context.

Spatial representation must never invent XP, completion, rank, certification, or personal progress semantics.

## Motion

Motion must communicate meaning rather than decoration.

Preferred categories:
- reveal/perception;
- relation;
- adaptation;
- manifestation;
- transition between canonical spatial contexts.

Reduced-motion and static manifestations must preserve information and hierarchy.

## Relationship to TKN ARCANE

Reference principles observed in TKN ARCANE:
- semantic tokens instead of decorative colors;
- intensity levels instead of uniform spectacle;
- canonical glyph provenance;
- topology-drift validation;
- geometry as an addressable system;
- semantic motion;
- material/light as meaningful layers.

TAIJIFU must NOT:
- import TKN glyphs as TAIJIFU symbols;
- copy ARCANE's MF geometry as TAIJIFU canon;
- depend on @tkn/arcane at runtime merely to obtain the aesthetic;
- allow TKN identity to visually dominate TAIJIFU;
- introduce external/paid runtime dependencies for the visual identity.

## Implementation direction

Extend the existing @taijifu/design-tokens grammar rather than replacing it.

Preserve the existing semantic token concepts:
- ink;
- paper;
- metal;
- tai;
- ji;
- fu;
- integration;
- typography;
- motion;
- mark sizing.

Add, through TDD and subsequent implementation planning:
- semantic intensity tokens;
- surface/material tokens;
- depth/elevation semantics;
- controlled glow/energy semantics;
- TAI/JI/FU motion roles;
- canonical mark manifestation rules;
- responsive ritual/artifact/signal behavior.

Exact calibrated color values and visual constants require the visual calibration/acceptance gate; they must not be invented as Canon.

## Acceptance principles

1. A screenshot rendering successfully is not visual validation.
2. Visual acceptance requires comparison with the official supplied reference and explicit project-owner approval.
3. Canonical content cannot be silently rewritten to fit layout.
4. The visual system must remain recognizable across Signal, Artifact, and Ritual manifestations.
5. TAIJIFU must remain visually and semantically distinct from TKN ARCANE.
6. The repository remains the canonical, self-contained implementation source.
