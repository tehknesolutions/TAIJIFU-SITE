# R01 Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Converge the existing TAIJIFU Home/Dojo Gate toward the approved R01 composition while preserving one Canon, one content flow, accessibility and the existing interactive experience.

**Architecture:** Recompose the current semantic `index.html` and its presentation CSS instead of creating a parallel Home. R01 governs hierarchy/composition; existing content modules, canonical Ω1 assets and Experience Graph remain authoritative for their domains. Environmental media stays optional and repository-owned, with a deterministic fallback.

**Tech Stack:** Node >=22, pnpm 10.17.1, TypeScript 5.9, Vite 7, Vitest 3, Three.js 0.180, semantic HTML/CSS.

**Spec:** `docs/superpowers/specs/2026-09-29-r01-home-implementation.md`

## Global Constraints

- `canon/TAIJIFU-CANON-1.0/` remains the martial Canon authority.
- Do not create a second Home, router, content registry or Canon representation.
- R01 governs product presentation, not martial Canon.
- Do not infer exact official calibration values from R01 pixels.
- Canonical Ω1 assets remain deterministic/effect-free under the existing asset contract.
- No paid SaaS, remote runtime asset dependency or local-only workflow requirement.
- TAI/JI/FU remain real canonical-route links.
- `Entrar no Dojo` must enter the existing interactive experience.
- Preserve keyboard navigation, responsive behavior and `prefers-reduced-motion` support.

## Review Focus

- Missing/failed environmental media must leave the complete Home readable and navigable.
- Narrow mobile viewports must preserve semantic priority rather than crop the desktop composition.
- Keyboard focus on the dark threshold must remain clearly visible.
- Presentation styling must not define or masquerade as official `--tj-calibration-*` values.
- Changes to the Home must not alter Canon content or the Experience Graph hierarchy.
