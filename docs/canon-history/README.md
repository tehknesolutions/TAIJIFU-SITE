# TAIJIFU Canon Histórico

Status: EPIC-002 — ACTIVE / archaeology-first
Authority: `tehknesolutions/TAIJIFU-SITE`
Issue: #166

## Purpose

Build the official historical domain as traceable knowledge, not as an unsourced narrative.

Model:

`Person → Organization → Event → Date/Period → Source → Claim → Provenance`

## Promotion rule

A historical statement may be inventoried without becoming Canon. Promotion requires an identifiable source, explicit claim, provenance record, conflict state and reviewed repository change.

## Current evidence boundary

The current `TAIJIFU-CANON-1.0` baseline primarily materializes martial structure. EPIC-002 therefore begins by creating the historical evidence model and inventory before promoting biographical/timeline claims.

Project conversations and uploaded project documents are valid migration sources under the Canon Foundation, but assistant-generated proposals are not Canon by repetition.

## Historical domains

1. Origin of TAIJIFU.
2. People and founders.
3. Organizations and relationships.
4. Timeline, events and periods.
5. Historical relationship with HNK.
6. Provenance and conflicts.

## Initial archaeology queue

- GPT Project TAIJIFU conversations.
- Project uploaded documents (`SITE TAIJIFU.txt`, Masters analyses/reports and PR-development records).
- `TAIJIFU-SITE` history, issues and pull requests.
- Previous TAIJIFU repositories catalogued by the Migration Ledger.
- TEHKNÉ/HNK repositories only as contextual evidence; they cannot override TAIJIFU Canon.

## Gate

`CANON_HISTORY_V1=PASS` only after the initial official history can be traced source → claim → provenance → status, with conflicts and unsupported gaps explicit.
