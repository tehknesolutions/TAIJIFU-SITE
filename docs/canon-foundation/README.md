# TAIJIFU Canon Foundation v1.0

Status: Sprint 001 / EPIC-001

## Authority

`TAIJIFU-SITE` is the unique official repository for TAIJIFU Canon. Platform, Experience, Academy, Masters and ecosystem products consume the Canon; they do not independently redefine it.

Flow: **Canon → Platform → Experience → Products**.

## Foundation components

1. Canon policy and versioning.
2. Canon Registry (`registry/`).
3. Source Registry (`sources/`).
4. Migration Ledger (`migration/`).
5. Knowledge Map (`knowledge/`).

## Existing material

This foundation extends the repository's existing Canon, authority, source-registry, archaeology and legacy-consolidation documentation. It does not silently replace prior material.

## Promotion rule

Material may be discovered or migrated without becoming Canon. Promotion requires provenance, classification and an explicit Canon status.

## Sprint 001 acceptance

EPIC-001 reaches v1.0 when the Registry, Source Registry, Migration Ledger and Knowledge Map have usable initial records and their governance is documented.
