## Authority

`TAIJIFU-SITE` is the unique official repository for TAIJIFU Canon. Platform, Experience, Academy, Masters and ecosystem products consume the Canon; they do not independently redefine it.

Flow: **Canon → Platform → Experience → Products**.

1. Canon policy and versioning.
2. Canon Registry (`registry/`).
3. Source Registry (`sources/`).
4. Migration Ledger (`migration/`).
5. Knowledge Map (`knowledge/`).
