# R01 — TAIJIFU Home / Dojo Gate North Star

Status: OFFICIAL PRODUCT DESIGN REFERENCE
Scope: Home / first viewport / Dojo Gate
Authority: product presentation reference; does not modify martial Canon
Source: reference image supplied and explicitly approved in the TAIJIFU GPT Project on 2026-09-29.
Reference artifact status: PENDING REPOSITORY INGESTION — the approved binary image exists in the GPT Project conversation but is not yet stored as an immutable repository artifact. Until ingestion is possible, this document records its approved composition contract; visual acceptance must not claim pixel-level verification from a clean checkout.

## Purpose

R01 is the visual target for the first public viewport of the TAIJIFU Web experience. Implementation should converge toward this composition while preserving semantic HTML, accessibility, responsive behavior, official content and the deterministic Ω1 brand system.

R01 is not a source for new martial Canon. Text/content must continue to come from authoritative TAIJIFU sources.

## Composition contract

### 1. Full-screen ceremonial dojo
- first viewport reads as a cinematic Japanese dojo threshold;
- dark timber architecture frames a luminous natural landscape;
- warm low-angle light and floor reflections create physical depth;
- atmosphere belongs to the Presentation layer, not to Ω1 asset geometry.

### 2. Header
- Ω1 + TAIJIFU wordmark at left;
- primary navigation across the upper region;
- search affordance;
- strong `ENTRAR NO DOJO` action at right;
- header remains visually integrated with the scene rather than becoming a generic application bar.

### 3. Central identity
- monumental Ω1 is the dominant focal point;
- `TAIJIFU` wordmark sits directly below;
- `ARTE MARCIAL DE SE ADAPTAR` is the supporting descriptor;
- central alignment and generous negative space are mandatory characteristics.

### 4. Side maxims
Left: `Firme na essência. Livre na forma.`
Right: `Mudar sem deixar de ser.`

The reference presents these as ceremonial vertical banners. Responsive implementations may adapt the physical layout without changing the text hierarchy.

### 5. TAI / JI / FU triad
Three equal paths occupy the lower central composition. R01 may visually emphasize the short axis names, but implementation must preserve the complete canonical labels from the authoritative Home inventory:
- TAI — `Essência · Permanência · Axis` — `O que deve permanecer?`
- JI — `Discernimento · Adaptação · Nexus` — `O que precisa mudar?`
- FU — `Manifestação · Fluxo · Flow` — `Que forma deve existir agora?`

Each path requires a distinct official semantic identity. Decorative approximations must not silently become official brand assets.

### 6. Primary threshold action
A large centered `ENTRAR NO DOJO` action sits below the triad and is the principal transition into the interactive experience.

### 7. Provenance / lower frame
The lower frame carries creator provenance, a restrained continuation/scroll cue and discreet HNK presence.

## Identity boundaries

- Ω1 canonical assets remain deterministic and effect-free according to the brand asset contract.
- Cinematic light, material depth, reflections and environmental atmosphere are Presentation-layer concerns.
- R01 does not authorize arbitrary neon, glassmorphism, HUD language or effects inside canonical Ω1 assets.
- Exact TAI/JI/FU/Integration calibration values remain UNRESOLVED until backed by authoritative provenance.
- Do not infer exact color values from pixels in the reference image and promote them as official calibration.

## Fidelity gates

Implementation review should compare at least:
1. overall first-viewport composition;
2. relative scale of Ω1;
3. header hierarchy;
4. side maxim placement;
5. TAI/JI/FU equality and spacing;
6. CTA prominence;
7. cinematic depth/materiality;
8. desktop and mobile legibility;
9. keyboard navigation and reduced-motion behavior;
10. correct use of official content and assets.

Until the approved R01 image is stored in the repository, gates 1–7 are reviewable against the approved project conversation but must be recorded as `REFERENCE ARTIFACT PENDING` rather than represented as reproducible pixel-level acceptance from the repository alone.

## Responsive rule

R01 is a desktop North Star, not a command to crop desktop composition onto mobile. Mobile must preserve hierarchy in this order: brand → TAIJIFU → descriptor → maxims → TAI/JI/FU → Entrar no Dojo → provenance.

## Definition of done for Home v1

Home v1 is visually reconciled when:
- its desktop first viewport is recognizably the same composition and hierarchy as R01;
- it uses official Ω1 assets and authoritative text;
- TAI/JI/FU paths navigate correctly and preserve their canonical labels;
- `Entrar no Dojo` enters the interactive experience;
- responsive and accessibility gates pass;
- any deliberate deviation from R01 is documented with a product/accessibility reason;
- repository-level visual acceptance explicitly reports the R01 binary artifact status until that artifact is ingested.
