# TAIJIFU Historical Canon Data

Machine-readable EPIC-002 records live here.

- `claims.json` — historical statements and status.
- `provenance.json` — source locators, classifications and conflict state.
- `timeline.json` — events linked to claims/provenance.

Empty arrays are intentional at initialization. A record enters these datasets only when its supporting source can be identified and located.

Human-readable archaeology and unresolved work live under `docs/canon-history/`.
